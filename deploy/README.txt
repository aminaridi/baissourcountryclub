BAISSOUR COUNTRY CLUB — WEBSITE DEPLOY PACKAGE
================================================

WHAT THIS IS
The complete new baissourcountryclub.com website, ready to upload.
Everything is static — no database, no PHP, no build step, no dependencies.

  index.html          the whole site (all pages: home, gallery, booking, directions)
  assets/i/           images (already optimized)
  assets/v/           videos (small ambient loops)

HOW TO DEPLOY
1. Upload the CONTENTS of this folder to the web root of the domain
   (usually public_html/ or www/ via cPanel File Manager or FTP),
   replacing the old site's files. index.html must sit in the root.
2. That's it. No server configuration needed. Works on any host
   (Apache, Nginx, cPanel shared hosting, Cloudflare Pages, Netlify...).

NOTES FOR THE WEBMASTER
- HTTPS should be enabled on the host (Let's Encrypt is fine).
- Fonts load from Google Fonts (fonts.googleapis.com) — leave that reachable.
- The forms open WhatsApp (wa.me/96181130345) and email
  (baissourcountryclub@gmail.com). They also auto-copy WhatsApp submissions
  to the email via FormSubmit.co: the FIRST submission after going live
  sends a one-time confirmation email to baissourcountryclub@gmail.com —
  open it and click "Activate" once, and auto-copies work from then on.
- The site is bilingual (English/Arabic). The language toggle stores the
  visitor's choice in their browser.
- To update content later, edit index.html or contact the site author.
